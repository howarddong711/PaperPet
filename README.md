# PaperPet

PaperPet 是一款面向 Zotero 桌面端的阅读伴侣插件。它在 Zotero 窗口中呈现一只会随阅读状态变化的桌面宠物，并在本地记录阅读会话、批注行为与估计有效阅读时间。

PaperPet 的第一目标是陪伴阅读。数据统计、可视化和养成机制服务于陪伴体验，不用于给用户打分或制造压力。

## 当前状态

项目已进入可运行原型阶段。当前版本已经能在 Zotero 9 中识别前台阅读、思考、快速浏览、批注、暂离和睡眠状态，并把阅读会话与合并后的语义事件写入 PaperPet 自己的本地 SQLite 数据库。界面仍使用纸页形测试伙伴，正式角色美术尚未开始。

- 产品名称固定为 `PaperPet`
- 首个目标版本为 Zotero 9 桌面端
- 首发平台为 Windows、macOS 和 Linux
- 数据默认仅保存在本地
- 角色美术尚未设计，当前优先实现可扩展角色框架

角色包的首版机器可读契约见 [角色包 JSON Schema](docs/character-pack.schema.json)。

开发环境和构建方法见 [开发指南](docs/development.md)。

## 核心体验

- 宠物可在整个 Zotero 窗口内自由移动
- 阅读、思考、批注、暂离等状态会驱动宠物动作
- 单击宠物获得轻量反馈，阅读报告和角色包安装统一从 Zotero 设置页进入
- 记录当前会话和历史阅读数据，并提供条形图和环形图
- 支持声明式 `.zpet` 角色包，为原创角色和用户自定义角色预留扩展能力
- 阅读记录页支持最近七天可视化、单篇论文详情、会话排除/恢复和本地 JSON 备份/恢复
- 在 Zotero 原生“设置”窗口提供独立的 PaperPet 设置页，包含外观、阅读识别、角色包安装和阅读报告入口

## 产品边界

首版不提供阅读目标、效率评分、排行榜、惩罚性连续签到，也不生成日报、周报、月报或年报。年度回顾是后续节日限定功能，由确定性统计生成数据，再由用户明确授权的 LLM 负责叙事。

## 研究口径

PaperPet 展示的是基于交互、视口和文档内容估计的“有效阅读时间”，不是眼动仪测得的真实注视时间。数字由确定性模型计算，模型依据和局限会公开说明。

## 本地开发

```bash
npm install
npm test
npm run build
```

构建产物位于 `.scaffold/build`，其中包含可安装的 XPI 文件。运行 `npm start` 前，需要根据 `.env.example` 配置 Zotero 9 可执行文件和独立开发配置目录。

## 安装

1. 从 [Releases](https://github.com/howarddong711/PaperPet/releases) 下载 `PaperPet.xpi`。
2. 在 Zotero 中打开“工具 → 插件”。
3. 点击齿轮按钮，选择“从文件安装插件”，然后选择下载的 XPI。
4. 在 Zotero“设置”左侧打开 PaperPet 页面，调整宠物大小、阅读识别参数，或安装 `.zpet` 角色包。

## 隐私

PaperPet 的阅读会话、动作事件、设置和报告数据默认只保存在 Zotero 数据目录下的本地 SQLite 数据库中。当前版本不提供云同步，也不会把论文标题、划线或笔记发送到外部服务。
